# Console Observatory 0.2.0: Windows build, a guided lesson, and visual inspectors
> **Superseded by 0.4.0.** This version only runs the bundled teaching game and other 32 KiB ROM-only cartridges; 0.3.0 and later open any Game Boy ROM.

Console Observatory is a native desktop Game Boy teaching lab: run a tiny original game, press Right, and follow the change from the joypad through a CPU instruction to memory, sprite memory, the next frame, and the tile bits that make the picture.

## What's new
- **Windows build**: a portable ZIP that runs on Windows 10/11 without installing anything.
- **Guided lesson** "Follow one press of Right": five steps, each ended by a real emulator event, with the system overview highlighting the path.
- **Run until written (F9)** for any memory byte.
- **Sprites and tiles** inspector: the sprite table and VRAM tiles decoded bit by bit.
- **Memory map** of all 64 KiB, coloured by writes and code execution.
- **System overview** with live values; dockable panels.
